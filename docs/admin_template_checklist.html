Nhóm 1: Bảo Mật & Quản Lý Tài Khoản (Security & Identity)

4 tính năng
Authentication & JWT Lifecycle ĐÃ HOÀN THIỆN

Đăng nhập, sinh Access/Refresh Token, cơ chế tự động refresh token trong Axios interceptor khi token hết hạn.

P1 Backend + Frontend
Backend:djangorestframework-simplejwt
Frontend:src/lib/api/client.ts (auto-refresh)
Phân Quyền Ma Trận RBAC ĐÃ HOÀN THIỆN

Quản lý Vai trò (Roles), Quyền hạn (Permissions) và Ma trận trực quan phân bổ quyền hạn cho từng chức vụ.

P1 Settings Module
Backend:RolePermissions, RoleHasPermission
Frontend:src/modules/settings/components/RBACMatrixTab.tsx
Hồ Sơ Cá Nhân & Đổi Mật Khẩu ĐÃ HOÀN THIỆN

Trang /profile cho người dùng xem & cập nhật hồ sơ, avatar, số điện thoại, đổi mật khẩu và xem trực quan vai trò, quyền hạn.

P1 Core Account
Backend:GET/PATCH /api/v1/auth/profile/, POST change-password
Frontend:client/src/modules/profile/ (Tabs: General, Security, Roles)
Nhật Ký Thao Tác (Audit Logs - django-pghistory) ĐÃ HOÀN THIỆN

Ghi vết mức PostgreSQL Triggers tự động 100%, ghi nhận sai khác Trước / Sau (Diffs), người thực hiện và Drawer xem chi tiết.

P1 Bảo mật & Giám sát
Backend:django-pghistory triggers + /api/v1/audit-logs/
Frontend:client/src/modules/audit-logs/ (DataTable + DiffDrawer)
📦

Nhóm 2: Hạ Tầng Dữ Liệu & Tiện Ích CRUD (Data & Common Utilities)

5 tính năng
DataTable Pro (DnD, Pin, Density) ĐÃ HOÀN THIỆN

Bảng dữ liệu kéo thả cột, ghim cột, ẩn hiện cột, thay đổi độ đậm nhạt và tự lưu preference người dùng vào LocalStorage.

P1 Common Component
Frontend:@/components/common/DataTable.tsx
Props:tableKey, columns, enableColumnDnD, pagination
Soft Delete & Audit Fields Chuẩn ĐÃ HOÀN THIỆN

Mọi model đều có sẵn IsActive, CreatedById, UpdatedById, CreatedAt, UpdatedAt, DeletedAt và bộ lọc mặc định loại trừ bản ghi đã xóa.

P1 Base Architecture
Backend:BaseAuditModel (server/core/base_models.py)
QuerySet:SoftDeleteQuerySet.alive() / .dead()
Tiện Ích Import / Export Excel Chuẩn ĐÃ HOÀN THIỆN

Nút Xuất Excel trong DataTable + Modal Tải file mẫu, kéo thả file Excel, bắt lỗi validate từng dòng và import hàng loạt.

P1 Fullstack Utility
Backend:openpyxl ExcelService + BaseERPViewSet export_excel
Frontend:@/components/common/ExcelImportModal & exportExcel
Quản Lý Tệp Đính Kèm Đa Hình (File Attachment) ĐÃ HOÀN THIỆN

Một component & API upload dùng chung cho mọi thực thể (hồ sơ nhân viên, bản vẽ kỹ thuật CAD, hợp đồng, chứng từ).

P1 Đa hình (Polymorphic)
Backend:Attachment model + /api/v1/attachments/
Frontend:<AttachmentManager entityType="item" entityId={id} />
Thao Tác Hàng Loạt & Thùng Rác (Recycle Bin) ĐÃ HOÀN THIỆN

Chọn nhiều dòng để Xóa/Duyệt hàng loạt. Xem danh sách đã xóa tạm và ấn nút Khôi phục (Restore) hoặc Xóa vĩnh viễn.

P2 Data Hygiene
Backend:POST /batch-delete/, /batch-restore/, /batch-hard-delete/
Frontend:DataTable rowSelection + RecycleBinDrawer

Nhóm 3: Cấu Hình Hệ Thống & Quy Tắc Tự Động (System Config & Rules)

3 tính năng
Dynamic Menu & Module Registries ĐÃ HOÀN THIỆN

Sidebar sinh động từ DB, quản trị đa tầng Cha - Con, kéo thả sắp xếp vị trí siêu mượt với animation dnd-kit chuẩn chỉ.

P1 Dynamic Routing
Backend:server/apps/modules/ (ModuleRegistries)
Frontend:ModuleTable.tsx (DnD kit vertical transform)
Bảng Tham Số Toàn Cục (System Settings) CẦN XÂY DỰNG

Trang cấu hình Key-Value: Tên công ty, Logo, Địa chỉ, Hotline, Định dạng ngày giờ mặc định, Ký hiệu tiền tệ, Cấu hình Mail SMTP.

P1 - Bắt Buộc Global Config
Backend:SystemSettings (SettingKey, SettingValue, DataType)
Frontend:src/modules/settings/views/GeneralSettingsView.tsx
Bộ Sinh Mã Tự Động (Number Series Generator) CẦN XÂY DỰNG

Tự động sinh mã chứng từ theo quy tắc: [PREFIX]-[NĂM]-[THÁNG]-[SỐ TỰ TĂNG] (VD: PO-2026-0001, WO-2026-0012, NV-00045).

P1 - Cực Quan Trọng Core Automation
Backend:SequenceRules & SequenceService.get_next_code()
Concurrency:select_for_update() chống trùng mã khi nhiều luồng
🎨

Nhóm 4: Trải Nghiệm Giao Diện & Thông Báo (UI/UX & Interactions)

4 tính năng
Tiêu Đề Trang Động (useModuleHeader) ĐÃ HOÀN THIỆN

Tiêu đề (Title) và mô tả (Subtitle) lấy tự động từ DB ModuleRegistries theo ModuleCode, không bị hardcode chuỗi tĩnh ở View.

P1 UI Hook
Frontend:client/src/hooks/useModuleHeader.ts
Usage:const { title, subtitle } = useModuleHeader("USER")
Hệ Thống Thông Báo Nội Bộ (Notification Bell) CẦN XÂY DỰNG

Chuông thông báo trên Header nhận cảnh báo sự kiện (Được duyệt đơn, Giao việc mới, Cảnh báo tồn kho), đánh dấu Đã đọc.

P2 Event System
Backend:Notifications (UserId, Title, Message, IsRead, Link)
Frontend:Header Notification Popover + Badge đếm số chưa đọc
Điều Hướng Breadcrumb Tự Động CẦN XÂY DỰNG

Tự động sinh Breadcrumb từ URL hierarchy và map tên tương ứng từ ModuleRegistries (VD: Cài đặt / Phân hệ & Điều hướng).

P2 UX Component
Frontend:@/components/common/SmartBreadcrumb.tsx
Next.js:usePathname() + useModules() context
Bộ Trang Lỗi Chuẩn (403, 404, 500) CẦN XÂY DỰNG

Trang giao diện chuẩn khi người dùng không có quyền (403 Forbidden), gõ sai link (404 Not Found), hoặc máy chủ quá tải (500 Error).

P3 Next.js Standard
Next.js:not-found.tsx, error.tsx, 403-view.tsx
UI:Ant Design <Result status="403" />

Nhóm 5: Trải Nghiệm Lập Trình & Sinh Code Tự Động (Developer Experience - DX)

2 tính năng
CLI Scaffolding: Sinh Module Mới Trong 1 Lệnh CẦN XÂY DỰNG

Vũ khí nhân 5x tốc độ: Gõ `python make_module.py suppliers` tự sinh toàn bộ Backend (model, serializer, viewset, url) và Frontend (types, services, hooks, table, form modal, view).

P1 - Đòn Bẩy Tốc Độ Dev Tooling
Script:scripts/scaffold_module.py
Output:Full CRUD Module sẵn sàng chạy trong 30 giây
Bộ Base Service & Base ViewSet Mở Rộng CẦN XÂY DỰNG

Chuẩn hóa sẵn các logic nghiệp vụ tự động: Lọc thông minh, Sắp xếp [-updated_at, id], Transaction Atomic ghi dữ liệu và tự điền CreatedBy/UpdatedBy.

P2 Backend DRY
Backend:server/core/base_viewsets.py, base_services.py

  • ✓ Script Python sinh Backend + Frontend
  • ✓ Thử nghiệm sinh 1 module Master Data từ DBML
  • ✓ Kiểm tra chuẩn linting & build 0 errors

Lắp ráp các module nghiệp vụ chuyên sâu theo đúng tài liệu DBML.

  • ✓ Sản phẩm & Biến thể (Bases & Variants)
  • ✓ Định mức BOM 4 tầng & Công thức sơn
